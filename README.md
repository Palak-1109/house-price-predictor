# 🏠 House Price Predictor

A machine-learning web app that predicts an estimated house price from property details.

## Features
- Area, bedrooms, bathrooms, floors and parking inputs
- Location selection
- Random Forest Regression
- Streamlit user interface
- Ready for GitHub

## Project Structure
```text
house-price-predictor/
├── app.py
├── train_model.py
├── dataset.csv
├── model.pkl
├── requirements.txt
├── README.md
├── .gitignore
└── screenshots/
```

## Run Locally
```bash
git clone https://github.com/YOUR_USERNAME/house-price-predictor.git
cd house-price-predictor
pip install -r requirements.txt
python train_model.py
streamlit run app.py
```

## Dataset
The included dataset is synthetic sample data for educational/demo use. Replace it with a verified real-world dataset for a production-quality project.

## Disclaimer
Predictions are estimates for educational purposes and are not professional property valuations.
